# 用户侧示例运行指南

## 目标

本指南帮助第一次使用的客户完成：安装 Python、准备依赖、启动本地程序、执行
无界面自测，以及运行 D102 / D201 / D202 示例。

## 1. 准备 Python 环境

建议使用 Python 3.10 或更高版本。在仓库根目录创建隔离环境并安装依赖：

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

macOS / Linux：

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 2. 有界面和无界面两种方式

有桌面环境时，启动本地程序并登录后，可以运行 `examples/gui/` 下的 Tkinter
面板。

服务器没有桌面环境时，不需要打开浏览器：

```bash
python examples/automation/ai_control.py status
python examples/automation/ai_control.py --help
python examples/cli/d102_quickstart.py --mode ws --dry-run
python examples/cli/d102_quickstart.py --mode http --dry-run
```

需要自动登录时，把凭据放在当前进程环境变量中：

```bash
export DI_PHONE='你的手机号'
export DI_PASSWORD='你的密码'
python examples/automation/ai_control.py login
```

不要把真实值写入命令历史、脚本或版本库。Windows PowerShell 使用 `$env:` 设置
同名变量。

## 3. D102 最小闭环

先确认服务端已启动并完成授权：

```bash
python examples/automation/ai_control.py status
python examples/automation/ai_control.py smoke
```

再做离线指令检查：

```bash
python examples/cli/d102_quickstart.py --mode ws --dry-run
python examples/cli/d102_quickstart.py --mode http --dry-run
```

最后连接本机服务接收少量消息：

```bash
python examples/cli/d102_quickstart.py --mode ws --listen 5
```

## 4. 常见问题

### 连接被拒绝

检查本地程序是否启动、数据服务端口是否为 `8080`，以及防火墙是否允许本机回环
连接。自定义端口时，使用示例中的地址配置或命令行参数。

### 返回未登录或未授权

先运行 `python examples/automation/ai_control.py status`，确认管理端状态；然后在有界面环境
完成登录，或在服务器上使用环境变量运行 `login`。不要在数据请求里手工填入
账号凭据。

### 没有桌面环境

不要运行 Tkinter 文件；使用 `examples/automation/ai_control.py`、D102 的 `--dry-run` 和
WebSocket CLI 示例即可完成基本测试。
